# DoktorABC Landing Page

Responsive landing page implemented with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server. For example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Browser support

The page supports current versions of Chrome, Firefox, Safari and Edge. Its responsive layout is optimized for 1920 px, 1280 px and 390 px viewports, with fluid behavior between those sizes.

## Project structure

- `index.html` – page structure and content
- `styles.css` – layout, components and responsive styles
- `script.js` – shared carousel interactions
- `assets/images/` – image assets supplied with the design

All assignment sections and interactions are implemented.
